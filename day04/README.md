# День 4 — Файлы, pathlib, JSON и CSV

## Цель

Научиться сохранять и восстанавливать данные из файлов.

## Изученные темы

- `open()` и `with` — работа с файлами.
- `pathlib.Path` — формирование и обработка путей.
- `json.dump()` — сохранение данных в JSON.
- `json.load()` — чтение данных из JSON.
- `csv.DictReader` — чтение CSV.
- `csv.DictWriter` — запись CSV.
- Кодировка UTF-8.
- Обработка отсутствующих файлов и некорректных данных.

## Выполненные задания

1. Сохранение списка студентов в JSON.
2. Сохранение списка студентов в CSV.
3. Чтение данных из обоих форматов.
4. Сравнение количества загруженных записей.
5. Импорт студентов из CSV с пропуском некорректных строк.
6. Формирование статистического отчёта.
7. Сохранение отчёта в текстовый файл.
8. Использование pathlib для работы с путями.

## Структура данных

- `data/students.json` — данные в формате JSON.
- `data/students.csv` — данные в формате CSV.
- `reports/report.txt` — статистический отчёт.

## Запуск

Из корневой папки проекта:

```bash
python -m day04.main
```

## Результат

Программа сохраняет данные, загружает их обратно, проверяет количество записей и формирует отчёт.
Некорректные строки CSV пропускаются без аварийного завершения программы.
