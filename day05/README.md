# День 5 — Модули, пакеты, docstring и тесты

## Цель

Привести код недели к структуре небольшого Python-пакета и покрыть ключевую логику тестами.

## Изученные темы

- `import` и `from ... import ...` — импорт модулей и отдельных имён.
- `__init__.py` — превращение каталога в пакет и реэкспорт функций.
- Docstring — документирование модулей и функций.
- `pytest` — запуск и организация тестов.
- `assert` — проверка условий в тестах.
- Тестовые функции с префиксом `test_`.
- `@pytest.mark.parametrize` — параметризация тестов.
- Понятие TDD-цикла: тест → падение → фикс → зелёный прогон.
