# День 2 — Условия, циклы, функции и обработка ввода

## Изученные темы

- Условные конструкции if / elif / else
- Циклы for и while
- Функции и возвращаемые значения
- Обработка исключений try / except
- ValueError и ZeroDivisionError

## Реализованные задачи

1. Модуль calculator.py с математическими операциями:
   - add() — сложение;
   - sub() — вычитание;
   - mul() — умножение;
   - div() — деление.

2. CLI-калькулятор с поддержкой операций +, -, *, /.
   Выход из калькулятора осуществляется командой exit.

3. Функция is_prime(n) для определения простых чисел.
   Вывод простых чисел в диапазоне от 1 до 200.

4. Функция validate_age(value) для проверки возраста
   в диапазоне от 0 до 120 включительно.

5. Обработка некорректного пользовательского ввода.

## Запуск программы

Из корневой папки проекта:

```powershell
python day02/main.py
```
