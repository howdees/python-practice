# День 3 — Списки, словари, множества и сортировки

## Цель

Научиться работать с коллекциями Python и выполнять анализ данных.

## Что изучено

- `list` — списки.
- `tuple` — кортежи.
- `dict` — словари.
- `set` — множества.
- `sorted()` и `key` — сортировка данных.
- `lambda` — короткие анонимные функции.
- List comprehension и set comprehension.
- `sum()`, `min()`, `max()` — математические операции.
- `Counter` — подсчёт повторяющихся элементов.

## Выполненные задания

1. Создан список из 15 студентов.
2. Реализован расчёт среднего балла.
3. Реализован вывод топ-5 студентов.
4. Добавлена фильтрация студентов по группе.
5. Добавлена сортировка по возрасту.
6. Добавлена сортировка по среднему баллу.
7. Реализован поиск повторяющихся имён.
8. Реализовано получение уникальных групп.
9. Сформирован текстовый отчёт.
10. Добавлено сохранение отчёта в файл.

## Запуск

Из корневой папки проекта:

```bash
python day03/main.py
```

## Результат

После запуска отчёт выводится в терминал и сохраняется в файл:

`day03/report.txt`

Функции анализа не изменяют исходные данные студентов.
Для сортировки используется `sorted()`, который создаёт новый список.
